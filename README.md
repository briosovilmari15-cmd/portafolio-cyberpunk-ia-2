# 🌃 Portafolio Profesional Cyberpunk con Inteligencia Artificial

Portafolio web profesional desarrollado con estética ciberpunk oscura, modo Dark/Light con contraste garantizado, efecto de fondo Matrix translúcido y diseño 100% responsivo[cite: 1, 3, 5, 7].

## 🎯 Objetivo del Proyecto
Dominar la técnica de *Prompt Engineering* aplicada al desarrollo web, convirtiendo requerimientos formales de software en código funcional, estructurado y desplegado públicamente[cite: 3].

## 🛠️ Tecnologías Utilizadas
* **HTML5** (Estructura semántica)[cite: 5, 7]
* **CSS3** (Estilos personalizados y estética ciberpunk)[cite: 5, 7]
* **Bootstrap 5** (Diseño responsivo y componentes)[cite: 5, 7]
* **JavaScript** (Efecto Matrix en Canvas y filtros dinámicos)[cite: 5, 7]
